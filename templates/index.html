JavaScript тілін үйренуге арналған ЖИ кері байланысы бар диагностика

Бұл қосымша магистрлік диссертациялық зерттеу аясында әзірленген. Мақсаты — JavaScript негіздерін үйренушілердің жиі жіберетін қателерін анықтау және жасанды интеллект (ЖИ) берген кері байланыстың педагог бағасымен қаншалықты сәйкес келетінін зерттеу.

Қатысу тәртібі

  1. Өзіңізге берілген немесе өзіңіз ойлап тапқан анонимді қатысушы кодын енгізіңіз (мысалы, JS-017). Атыңызды жазбаңыз.
  2. JavaScript негіздері бойынша 10 сұрақтан тұратын тестті орындаңыз.
  3. {{ tasks|length }} практикалық тапсырманы орындаңыз: код жазып, шешіміңізді қысқаша түсіндіріңіз.
  4. Әр тапсырмадан кейін ЖИ дайындаған кері байланысты оқыңыз.

Барлығы шамамен 30–40 минут алады. Әр тапсырмаға бір рет жауап беріледі.

Қандай деректер жиналады

  • анонимді қатысушы коды;
  • тест жауаптары және практикалық тапсырмаларға жазған код пен түсіндірме;
  • жауап жіберілген уақыт;
  • ЖИ талдауы және педагогтің тексеру нәтижесі.
